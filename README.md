# Wayfold

Игра о территории, где каждый поход перекраивает карту.

**Играть:** https://shirokovst.github.io/wayfold/

В деревнях растут жители. Отправляйте их отрядами захватывать соседние деревни: по пути отряды перекрашивают каждую клетку в свой цвет, а земля приносит золото. На золото ставьте фермы и сторожевые башни и превращайте деревни в города, чьи жители сражаются как солдаты. Победит тот, кто захватит все деревни соперника.

- Активная пауза: во время паузы можно отдавать приказы.
- Четыре типа карт (материк, озёра, полуострова, острова) трёх размеров.
- Три уровня соперника и короткое обучение.
- Интерфейс на английском и русском, вся графика нарисована кодом.

## Запуск

Нужен [Node.js](https://nodejs.org/) 20+.

```bash
npm install
npm run dev
```

Игра откроется на `http://127.0.0.1:5180`.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | сервер разработки |
| `npm test` | тесты (Vitest) |
| `npm run build` | проверка типов и сборка в `dist/` |
